MONK FOR WINDOWS

Connect your browser.

Application blocking works immediately. Complete this one-time step for website allowlists in Chrome, Edge, Brave, or Chromium.

  1. Open your browser's extensions page and turn on Developer mode.
  2. Choose Load unpacked.
  3. Select the browser-extension folder inside your Monk installation.

The extension reads only the active domain allowlist through a local Windows bridge. It does not receive your intention or application list, and it never sends data over the internet.
